# Security Policy

If you believe you have found a security issue in the `.luku` specification or its trust model, please report it privately before opening a public issue.

Examples include:

- ambiguity that could lead to inconsistent verification
- canonicalization weaknesses
- trust-chain bypass scenarios
- archive integrity bypasses
- replay, relinking, or downgrade risks

Please contact:

info@lukuid.com

Do not publicly disclose vulnerabilities affecting live trust or verification behavior until coordinated remediation is available.
