# Contributing

Thanks for your interest in improving the `.luku` specification.

## Scope

This repository contains the specification text for the `.luku` protocol. It is not the place for SDK, CLI, firmware, or backend implementation issues unless they directly affect the specification.

## How to contribute

You may contribute by:

- opening an issue for clarification requests
- proposing wording improvements
- suggesting protocol changes with rationale
- reporting inconsistencies between sections

## Expectations

Please keep proposals:

- precise
- version-aware
- backward-compatibility conscious
- security-conscious

## Normative changes

Changes that affect verification rules, canonicalization, trust semantics, or compatibility should be proposed with:

- motivation
- security impact
- compatibility impact
- suggested wording
