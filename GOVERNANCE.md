# Governance

The `.luku` specification is maintained by LukuID Oy.

## Canonical authority

This repository is the canonical public source for the `.luku` specification.

Tagged releases represent stable specification versions.

## Specification evolution

LukuID Oy reviews and approves normative changes to:

- archive structure
- canonical serialization
- verification workflow
- trust semantics
- compatibility rules

## Compatibility expectations

Backward-compatible additions may be introduced in minor versions.

Breaking changes require a major version increment.
